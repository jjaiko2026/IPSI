# data — 대학별 입시 자료

대학 하나에 폴더 하나입니다. 웹페이지(전략판)는 이 폴더의 파일을 그대로 받아서
전형별 환산점수와 합격선 대비 위치를 계산합니다.

```
data/
  대학/
    경북대학교/
      모집요강.json     ← 전형별 반영비율·환산표·수능최저 (직접 채우는 파일)
      입시결과.json     ← 과년도 70%컷·50%컷·경쟁률·충원율
      원문/             ← 모집요강 PDF, 캡처, 발표자료 원본
      추출/             ← PDF에서 자동 추출한 CSV (참고용, 원문으로 검증 필요)
  bundle.json           ← 전체 합본. 웹페이지에 한 번에 넣을 때 이 파일을 씁니다
  index.json            ← 대학별 입력 진행 상황
```

## 쓰는 순서

1. `원문/`에 그 대학 모집요강 PDF와 과년도 입시결과 자료를 넣습니다.
2. 원문을 보고 `모집요강.json`의 `전형`과 `입시결과.json`의 `결과`를 채웁니다.
3. `python3 tools/build.py` — `bundle.json`이 다시 만들어집니다.
4. 전략판에서 **자료 → 파일 불러오기**로 `bundle.json`(또는 `data/대학` 폴더 통째로,
   또는 대학 폴더 하나)을 넣으면 전형 목록이 뜨고, 거기서 지원 후보로 담습니다.

새 대학: `python3 tools/new.py 서울대학교 서울`

## 모집요강.json

```json
{
  "대학명": "경북대학교",
  "지역": "대구",
  "학년도": 2028,
  "출처": "경북대학교[대구]_2028.pdf",
  "갱신일": "2026-09-12",
  "전형": [
    {
      "전형명": "실기/실적(예·체능)",
      "학과": "체육학부(체육학전공)",
      "구분": "수시 · 교과 | 수시 · 종합 | 수시 · 실기 | 정시",
      "모집인원": 20,
      "반영비율": { "교과": 30, "수능": 0, "실기": 70, "면접": 0 },
      "교과반영": {
        "교과군": ["국어", "수학", "영어", "사회", "과학"],
        "학년가중치": { "1": 1, "2": 1, "3": 1 },
        "등급점수": [100, 96, 88, 76, 60]
      },
      "수능반영": {
        "국어": 0, "수학": 0, "영어": 0, "탐구": 0,
        "영어등급점수": [100, 95, 88, 80, 70, 58, 44, 28, 10]
      },
      "수능최저": { "적용": false, "상위영역수": 2, "등급합": 6 },
      "실기": { "종목": "Z자 달리기, 제자리멀리뛰기" },
      "확인": "미확인 | 확인됨",
      "메모": ""
    }
  ]
}
```

- **등급점수**는 1등급부터 순서대로 적습니다. 내신 5등급제면 5개, 9등급제면 9개.
  대학마다 표가 다르므로 모집요강의 표를 그대로 옮기는 것이 가장 정확합니다.
- **반영비율** 합이 100이 아니어도 비율대로 계산하지만, 원문과 맞는지 확인하세요.
- **확인**을 `확인됨`으로 바꾸면 진행 상황(`index.json`)에 집계됩니다.
  지금 들어 있는 전형은 PDF에서 자동으로 뽑은 초안이라 전부 `미확인`입니다.

## 입시결과.json

```json
{
  "대학명": "경북대학교",
  "결과": [
    {
      "학년도": 2027,
      "전형명": "실기/실적(예·체능)",
      "학과": "체육학부(체육학전공)",
      "기준": "등급",
      "컷70": 2.6,
      "컷50": 2.3,
      "경쟁률": 8.4,
      "충원율": 105,
      "메모": ""
    }
  ]
}
```

- **기준**: 대학이 합격선을 내신 등급으로 공개하면 `등급`, 환산점수로 공개하면 `점수`.
- **컷70**은 합격자 하위 70% 지점(보통 실질 합격선), **컷50**은 중간값입니다.
- 전형명·학과는 `모집요강.json`의 값과 같게 적어야 자동으로 짝이 맞습니다.
